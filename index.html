Final Web App Blueprint

AR6 極端降雨變化預測平台

以 TCCIP AR6 格點指標建立靜態部署、前端互動、離線預測查詢的研究型 Web App。 主目標固定為 Rx1day change，也就是未來情境期與 OBS 1995-2014 的差值。

Research Target

預測問題與公開資料介面

本平台不在瀏覽器訓練模型，也不做即時重量級推論。Python 先在本機完成 modeling table、 spatial block CV、批次預測與區域聚合，GitHub Pages 只負責載入靜態 JSON 與互動呈現。

01

主 target

Rx1day change = future Rx1day - OBS_1995-2014，所有情境與時段都採一致定義。

02

輔助特徵

整合 TX90p、PRCPTOT、SDII、CDD、CWD、HWDI 的 change 特徵與 predictor spatial lag。

03

查詢輸出

格點查詢使用 grid_predictions.json，行政區摘要使用 region_predictions.json。

Workflow

原始 CSV 讀取沿用尾逗號修正策略，將 -99.9 視為缺值，格點資料以有效值交集建表。

Build

Modeling Table

Train

Model Platform

Export

Offline Prediction

批次輸出 change、future、risk percentile、risk level，前端只讀 JSON。

Explore

Static Web App

保留既有地圖與統計圖，新增模型比較頁與可點選格點的預測查詢頁。

Scope

成果驗收範圍

網站包含研究背景、地圖探索、完整模型比較、預測查詢、結論與限制。所有頁面皆使用相對路徑， 可直接部署到 GitHub Pages，不依賴伺服器執行 Python。
